05 / FUNDAMENTO MATEMÁTICO

¿De dónde sale el valor verdadero?

Partimos de xy y′ = x² − y². Con u = y², se obtiene una ecuación lineal:

u′ + (2/x)u = 2x

El factor integrante x² permite integrar:

(x²u)′ = 2x³ → y² = x²/2 + C/x²

La condición inicial determina la constante:

C = x₀²y₀² − x₀⁴/2

Se elige la rama con el signo de y₀, en un intervalo donde x e y no se anulan. Para el ejercicio oficial:

y(x) = √(x²/2 + 7/(2x²))

Precisión y alcance. Los cálculos conservan la precisión de coma flotante. Solo se redondea su presentación; al copiar se incluyen los valores completos. Heun es de orden global 2 y Euler de orden 1, pero la comparación mostrada corresponde exclusivamente al PVI y al paso elegidos.
